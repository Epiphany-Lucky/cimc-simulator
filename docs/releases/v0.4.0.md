# CIMC Studio 0.4.0

本版的机器码、界面、安装及发布验证记录见 [0.4 验收记录](https://github.com/Epiphany-Lucky/cimc-simulator/blob/main/docs/validation-v0.4.md)。

本版可把 Bootloader 和多个应用同时装入仿真内部 Flash，并选择从哪张向量表启动。固件卡新增“多固件”入口，支持持续添加 HEX/BIN、逐个配置 BIN 链接地址、选择启动项及高级自定义启动向量。取消保留当前运行状态，成功烧录后再运行。文件数量不固定为两个或三个槽位。

镜像共同占用 GD32F470VET6 的 512 KiB 内部 Flash。稀疏 HEX 的未写空洞可由其他文件填充，实际写入重叠、越界、缺失向量及未写入的入口被拒绝。单个原始文件最多 4 MiB，完整固件集合导出 JSON 最多 8 MiB，HTTP 请求最多 16 MiB。

随包增加三份真实 Keil 固件：

| 固件 | 链接/向量地址 | 观察方式 |
|---|---|---|
| `bootloader_probe` | `0x08000000` | `BOOT READY` 后从 CH340/USART0 发送 `1` 或 `2` |
| `app_a_probe` | `0x08010000` | `APP A READY`，PD10/LED1 |
| `app_b_probe` | `0x08020000` | `APP B READY`，PD11/LED2 |

Bootloader 实际执行设置 MSP、重定位 VTOR 和 BX 跳转，各应用通过独立 SysTick 处理器与 SRAM 邮箱证明运行位置。直接选择 B 启动则不经过 Bootloader；缺失应用由 Bootloader 固件报告。LED 仍需在实际可连接排针上添加外接跳线，原板线路、OLED、ADC、SPI Flash 和串口固定网络保持不变。[完整固件契约和构建摘要](https://github.com/Epiphany-Lucky/cimc-simulator/blob/v0.4.0/firmware/BOOT_PROBES.md)

工程格式升级为 v3，保存完整固件集合、启动向量与接线/串口/ADC 设置。导入先整体校验，成功后从选定入口复位；旧 v1/v2 工程仍可导入并保留当前固件。工程不保存运行中的寄存器、RAM 和外置 SPI Flash 内容。

修复 SysTick 调度变慢：中断进入与返回会在同一执行批次内继续处理，不再每次都额外等待12ms；指令计数不再包含被中断截断、尚未执行的指令。宿主时间片检查保持暂停、关闭和界面响应，新增分块/单步一致性、密集中断与冻结安装包性能回归。SysTick仍按执行指令推进，此修复不代表硬件时钟或墙钟1ms精度。

同一Windows主机三次测量的SysTick中位速率由36,491增至729,941条/秒，约提升20倍，真实中断次数同步提升。最终Windows安装/覆盖/卸载、HTML界面、Ubuntu22.04、Debian12与同包WSL验收均通过；最终源码、两平台打包和安装检查见[成功的CI运行](https://github.com/Epiphany-Lucky/cimc-simulator/actions/runs/43804681787)。

本次仍是数字功能仿真；不新增 FMC 在线自写、完整 IAP/OTA、系统 ROM Bootloader、DMA、RTOS 或任意 Keil 工程兼容承诺。Windows、Ubuntu/Debian 与 HTML 本地版继续共用执行内核，安装、升级、卸载方式见 [安装说明](https://github.com/Epiphany-Lucky/cimc-simulator/blob/v0.4.0/docs/install.md)。

0.4 提供 `CIMC-Studio-0.4.0-Setup-x64.exe`、`cimc-studio_0.4.0_amd64.deb` 及同版本 Windows/Linux/HTML 便携包。五个文件均来自同一次已通过的CI，附SHA256SUMS与验收记录。源码仓库与 Releases 公开；GHCR 的 Windows/Linux Packages 当前仍为私有，不能匿名拉取。

按项目所有者要求，每次更新同步软件、GitHub 和公告。新版本完整验收及发布验证后才清理旧版安装分发附件和对应 Packages 版本，保留源码、提交、标签、Release 公告与验证报告；用户安装目录及导出文件不属于清理范围。

本次已完成更新入口验证：0.3客户端可检测0.4，Windows/Linux/HTML下载正常；两平台Packages回拉通过后，旧0.1/0.2/0.3安装附件、旧0.3 Packages版本及本地旧分发文件已清理。历史源码和公告继续保留，详见[清理记录](https://github.com/Epiphany-Lucky/cimc-simulator/blob/main/docs/releases/cleanup-v0.4.0.json)。
