# CIMC Studio 0.1.0 · V1.0 开发预览

第一版可运行交付：Windows EXE + HTML 本地网页版，目标为用户选定的 GD32F470 V1.0。

## 下载与启动

- **Windows 桌面版**：下载 `CIMC-Studio-0.1.0-win-x64.zip`，完整解压，运行 `CIMC-Studio.exe`。
- **HTML 网页版**：下载 `CIMC-Studio-0.1.0-html-local.zip`，完整解压，运行 `Open-Web.cmd`，保持服务窗口开启。
- 首次使用点击“载入示例固件”→“运行”。Keil 示例机器码会驱动 OLED、LED 和串口回复。

两种版本都已内置 ARM 仿真内核，无需安装 Python 或 Keil。HTML 版需要随包本地内核，不是双击单个 HTML 就能在浏览器内执行 ARM 的 WASM 版本。桌面版使用系统 WebView2 Runtime。

## 本版能力

- 真实 Keil HEX/BIN 装载及 Cortex-M4 执行，运行/暂停/单步/复位。
- V1 原理图排针与固定网络、LED/KEY 虚拟跳线、OLED 显示。
- CH340、RS485、RS232 和 TTL 的轮询数据通道；V1 的 RS232/RS485 通过 H6 选择，共用 USART1。
- 接线工程保存/恢复、日志和 OLED 截图导出。
- 21 项自动测试、浏览器交互检查、独立打包内核和 Windows WebView2 实际运行检查通过。

## 当前边界

这是功能仿真预览，未实现 UART 中断、DMA、硬件 I²C、ADC、SD、SPI Flash 等完整外设，不保证任意 Keil 工程。已支持范围和逐项证据见 `docs/validation-v0.1.md`。工作台为 V1 原理图接线视图，没有使用其他版本实物图冒充 V1。

资料和源码在发行包内保留，完整源码也随本版本标签提供。SHA-256 校验值见附件 `SHA256SUMS.txt`。
