# CIMC Studio 0.2.0

本次修复笔记本窗口超出屏幕，并增加 V1 板载 ADC、SPI Flash 和固定接线管理。

- 窗口按工作区及 DPI 适配，网页提供短屏布局。
- ADC 旋钮固定接 PC0，0–3.3 V；真实固件采样后更新 OLED/串口。
- GD25Q40E 512 KiB SPI Flash，支持读取 ID、读、页编程、擦除及状态轮询子集。
- 原固定外设端点锁定；LED/KEY 保留手动排针跳线。
- RS232/RS485 通过模式开关按原图切换 H6；CH340 H7 固定连接。
- OLED 四条固定线直接显示；侧栏可离线查看四页原始原理图，翻页、缩放并下载原 PDF。
- v2 接线工程保存模式和 ADC 电压，兼容迁移标准 v1 工程。

下载 Windows 完整包后双击 `CIMC-Studio.exe`；HTML 本地包双击 `Open-Web.cmd`。均须完整解压，均自带固件执行内核，不需要真实开发板或 COM 驱动。

49 项内核/固件/接口测试通过，另有浏览器及短屏交互验收。完整验证及发行包结果见随包 `docs/validation-v0.2.md`。

此版本为开发预览，ADC/SPI 仅支持文档中的轮询模式子集，未实现 DMA/外设中断或完整器件时序，不保证任意 Keil 固件兼容。Flash 数据保存在本次内核会话中，关闭服务后不保留。
