# 0.9.0 SDIO 轮询与虚拟 TF 卡

2026-11-24 用户确认在 CIMC Studio 中加入 SDIO 控制器和虚拟卡读写模型。功能覆盖两款板卡、内核寄存器、工作台和发行，按复杂任务处理。实现复用 ARM MMIO、RCU、板卡固定网络、现有 HTTP 服务和工作台状态刷新。

两版原理图的 CARD1 固定网络采用 PC8～PC11 传输数据，PC12 为时钟，PD2 为命令，PE2 为低有效卡检测。仿真采用 1 位及 4 位 SDIO 轮询，字节寻址的 SDSC 镜像作为扇区后端。工作台提供镜像挂载、只读挂载、导出和弹出。

复用 081501 原 TF 驱动和 FatFs 构建独立 ARMCC5 探针。验收验证两板 FAT32 挂载、777 字节写入及读回、复位保留、只读保护和未插卡行为。用户固件工程留在原位置。详见 [验收记录](../../validation-v0.9.0.md)。
