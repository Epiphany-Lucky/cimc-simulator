# CIMC Studio 0.5.0

2026-11-16 · 开发预览

## CIMC V2 板卡

在开发板标题选择 V2.0，再点击“载入 V2 Bootloader + App”，即可共同烧录本次提供的两份实际固件。点击运行后，Bootloader 通过自己的 SysTick 倒计时与跳转代码启动应用。串口自动切到 RS485，可读取版本、ADC 和温度，或进入 Bootloader 完成应用升级。

V2 沿用 V1 的原理图接线界面，五页原始 PDF 可翻页、缩放和下载。固定网络按原图锁定，代码中的外接跳线可增删。V2 使用独立信号映射，USART1 为 PD5/PD6，方向控制 PE8，OLED 为 PB8/PB9，LED1 的示例跳线接 PE6。板载 VR1 固定接 PC0，PC1 外接输入、DAC0 观察口与 PT100 使用可编辑示例跳线。信号输入可调，拆接线会影响实际转换与收发。板载 SPI Flash 使用原图的 SPI0 PB3/PB4/PB5 与 PA15 片选。内部 Flash 的编程、擦除、复位和保存由实际 MCU 访问驱动。

协议区可生成所选设备 ID 的命令与 CRC。升级时先发送“进入 Bootloader”，进入后发送“准备接收升级包”，用“发送 BIN 文件”发送含头的 app_update.bin，收到固件应答后发送“写入应用并重启”。串口日志中的回复来自 ARM 固件执行。

工程导出包含当前板卡、接线、固件集合及内部 Flash 内容。打开另一板卡的工程时会恢复相应配置。

## 软件内更新

打开设置并检查更新，点击“下载更新”可在应用内查看进度。下载完成后自动检查大小和 SHA-256，保存工程后点击“安装并重启”。Windows 沿用实际安装目录，退出当前应用后安装并重新启动。Ubuntu/Debian 系统安装通过系统授权执行，便携版可打开已校验包所在目录。

断网、下载中断和校验失败会显示错误并允许重试。发行文件仍可从本页直接下载。

## 发布与验证

提供 Windows 安装版、Windows 便携版、HTML 本地包、Ubuntu/Debian DEB 与 Linux 便携包。两平台 CI、冻结包、Windows 原生桌面及同包 WSL 验收记录保存在源码中的 docs/validation-v0.5.md，发行附件另有 SHA-256 清单。

后续版本继续同步源码、软件和公告，并在新版发布验收成功后清理被取代的安装分发文件，保留源码、标签、公告和验证记录。

## 支持范围

V2 依据用户本次补齐的代码适配。本次补入完整五页 V2 原理图并核对固定网络与排针编号。代码接线作为可编辑示例。实板、电气时序和其余未建模外设仍需独立验证。PT100 实现用户驱动使用的 SPI 16 位配置转换子集，ADC/DAC 为功能模型。V2 每条执行指令推进 240 个 SysTick 输入 tick，倒计时由真实中断代码推进。更复杂的中断嵌套、DMA、RTOS 和未建模外设通过运行诊断报告。
