# CIMC Studio 0.6.1

2026-11-17 · 开发预览

## 软件内更新重启

修复Windows软件内升级完成后，新冻结内核继承旧PyInstaller临时运行目录，出现 `Failed to load Python DLL` 的问题。桌面宿主启动内核、更新辅助进程交接及新版重新启动分别使用独立冻结运行环境。旧版辅助进程启动新版桌面的路径也纳入兼容验证。

设置中的“检查更新”“下载更新”“安装并重启”继续使用官方发行源、大小和SHA-256校验，并沿用实际安装目录。升级前保存当前工程，新版启动后可恢复原固件集合、引脚接线和颜色。

## 定时器与交互

延续0.6.0的TIMER0～TIMER13、SysTick、FWDGT/WWDGT、定时器观察面板、六种主题颜色及按键响应。定时器仍由真实固件寄存器操作驱动，各类型具有对应的位宽、通道和模式。功能与覆盖范围见 [0.6.0公告](v0.6.0.md)。

## 发布验收

提供Windows安装版、Windows便携版、HTML本地包、Ubuntu/Debian DEB及Linux便携包。本版新增真实冻结旧环境交接检查，并重新执行两平台构建、安装、固件、界面、同包WSL和正式软件内升级验收。实际结果逐项记录于 `docs/validation-v0.6.1.md`。

发行验收完成后清理旧安装分发，源码、标签、公告和验证记录继续保留。软件使用确定性功能时钟，完整DMA、RTC日历、WFE及深度休眠电源域、实板电气和逐周期时序需要独立实现及验收。
