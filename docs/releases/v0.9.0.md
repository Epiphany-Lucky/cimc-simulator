# CIMC Studio 0.9.0

V1 和 V2 新增 SDIO 控制器和虚拟 TF 卡。工作台可挂载原始 .img 镜像，选择可写或只读方式，查看固件实际读写的扇区数，并导出读写后的镜像。

原图中的 PC8～PC12、PD2 和 PE2 固定连接已接入模型，固件可使用 1 位或 4 位轮询传输。虚拟卡采用 SDSC 寻址和 512 字节扇区，支持最大 128 MiB 且容量可精确编码的镜像。文件系统由固件处理，可挂载 FAT32 镜像。镜像在 MCU 复位后继续保留，关闭应用前请导出需要保存的修改。

本版支持 SDIO 轮询。SDIO DMA、SDIO 中断、SDHC、SDXC 与真实总线电气时序尚未建模。功能验证范围和取证见 [0.9.0 验收记录](https://github.com/Epiphany-Lucky/cimc-simulator/blob/v0.9.0/docs/validation-v0.9.0.md)。

本版分发 Windows 安装版、便携版、HTML 本地包、Ubuntu/Debian 安装版及 Linux 便携版。

V1 和 V2 均运行了复用原 081501 TF 驱动与 FatFs 的 ARMCC5 验收固件。两板成功挂载 64 MiB 的 FAT32 镜像，写入 777 字节，并在 MCU 复位后重新读回。五个分发文件均来自[同一次验证构建](https://github.com/Epiphany-Lucky/cimc-simulator/actions/runs/45399344258)。
