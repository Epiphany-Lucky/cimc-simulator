# 2026-11-20 PROJECT1 180 MHz 启动修复

用户报告 PROJECT1 的 V1 LED 全灭，PC 停在 `0x08000E50`。该处是 `HAL_PWREx_EnableOverDrive()` 超时后进入的错误循环，发生在 GPIO 和任务初始化之前。

产品提交 `f18e70cabdc9e5a5d7a94df1e72ea648057bf74f` 让 V1 复用已有的 V2 PMU 高驱动状态映射，新增两板型核对。原 PROJECT1 HEX 在本机源码、Windows 冻结包和同一 Linux 发行包上恢复运行，按原始值点亮第 1、3、5、6 盏灯。

选定 CI `44696920571` 的四个作业全部通过，0.7.1 已公开。Windows、Linux 安装包和公开更新资源的摘要核验完成。本机匿名更新查询受限，实际改用官方安装器就地更新并恢复原六线工程。双平台 Packages 与新版本均核验后完成已枚举旧包清理。更详细的初始状态和证据见 [0.7.1 验收](../../validation-v0.7.1.md)。
