# CIMC Studio 0.6.1 使用说明

## 打开

当前安装与软件内更新步骤见 [安装说明](install.md)，本版实际验收见 [0.6.1记录](validation-v0.6.1.md)。工作台支持V1/V2，板卡选择决定固定网络及外设连接。

- Windows 完整包：完整解压，双击 `CIMC-Studio.exe`。窗口按当前工作区及系统缩放适配。
- HTML 专用包：完整解压，双击 `Open-Web.cmd`，保持服务窗口开启。
- 两种界面均使用本地 ARM 内核。所有文件保存在本机，无真实开发板、COM 口或 CH340 驱动要求。

左侧点击“原理图”，可在工作台内查看原始 V1.0 四页资料：MCU/排针、板载外设、电源、串口通信。支持翻页、适合宽度、放大与原 PDF 下载；按 Esc 或关闭按钮返回工作台。页面预览与 PDF 都随包提供，无需联网。

## 先验证示例

1. 点击“载入示例固件”，加载真实 Keil HEX 和 12 条 LED/KEY 示例跳线。
2. 点击“运行”，OLED 显示固件画面，CH340 终端显示启动消息与 `FLASH JEDEC C84013`。后者来自实际 SPI 读取，示例不擦写 Flash。
3. 按 KEY1–KEY6，固件读入 GPIO，更新 LED，并在 OLED 显示按键次数。
4. 拖动 ADC 旋钮或滑杆调整 PC0 的 0–3.3 V 电压。聚焦旋钮后可用方向键、PageUp/PageDown、Home/End 调整。采样值在固件实际转换后更新；暂停时改变电压不会伪造新样本。
5. 串口输入 `L` 翻转 LED、`C` 清空计数、`A` 返回 ADC 值；回复由固件生成。OLED 同时显示 ADC 数值。
6. 在“我的接线”删除 LED 跳线，该 LED 将失去原 GPIO 驱动。选择空闲 GPIO 与 LED/KEY 排针可重新连线。保存/打开接线使用 JSON 文件，同时保存串口模式和 ADC 电压。

## 固定接线与串口模式

原板固定电路不可更改。PC0 ADC、PB8/PB9 OLED、PB12–PB15 SPI Flash、串口专用端点、电源/地和未实现的原板外设端点均不可作为用户跳线端点。只读的系统连接没有删除按钮，导入工程或直接调用接口同样不能绕过约束。

OLED 四条线已直接显示：PB8→SCL、PB9→SDA、3V3→VCC、DGND→GND。在“我的接线”中标为原板固定线，不计入用户跳线数，也不能删除。

RS232 / RS485 共用 USART1。使用“接口选择”开关，系统按原图切换 H6：

| 模式 | 系统连接 |
|---|---|
| RS485（默认） | H6.1↔H6.3、H6.2↔H6.4 |
| RS232 | H6.3↔H6.5、H6.4↔H6.6 |
| CH340（固定） | H7.1↔H7.3、H7.2↔H7.4 |

切换终端页签只改变查看/发送通道，不改变接口模式。切换接口模式会清空 USART1 尚未处理的接收队列。向未选中的接口发送数据不会送入 MCU。

V0.1 的标准 H6/H7 工程可自动迁移；H6 不完整、两种收发器混接或改接固定端点的旧工程会拒绝导入，保持当前工程不变。

## 使用自己的固件

导入 Keil 输出 `.hex` 或 `.bin`。BIN 默认装载地址 `0x08000000`，必须与链接地址一致。HEX 校验和、Flash 范围和复位向量会被检查。

LED/KEY 通过原排针手动连到空闲 GPIO；其余专用外设按 V1 原图固定。导入固件和复位保留用户跳线、ADC 位置、串口模式以及外部 Flash 内容。“载入示例”将用户跳线替换为示例 12 条，并选择 RS485。

本版新增 ADC0/1/2 的 PC0/通道10、软件触发、单次轮询转换；SPI1 支持主机、8位、MSB、mode 0/3、软件片选的 GD25Q40E 指令子集。固件仍需正确开启时钟及配置 GPIO。验证源码 `firmware/adc_probe.c` 和 `firmware/spiflash_probe.c` 可作最小用法参考，后者会擦写仿真 Flash。

Flash 面板展示真实命令与读写/擦除计数。容量为 512 KiB，初始全 FF；MCU 复位保留数据，关闭内核后不保存到磁盘，接线工程也不保存 Flash 内容。写入有 WEL/WIP、页回绕和 NOR 只能把 1 写为 0 的约束；延迟按仿真指令进度实现，不代表真实器件耗时。

USART RX/IDLE 中断、定时器触发 ADC/DAC 与全部 TIMER 实例的本版范围见更新公告。DMA、ADC 扫描/连续、硬件 I²C、SD、Flash 双/四线及保护寄存器等访问仍按具体支持范围报告诊断。

数字键 1–6 可按下对应 KEY，Space 运行/暂停；设置中可关闭快捷键或减少动画。OLED 可导出 PNG，串口和诊断可导出文件。

## V2 板卡与用户工程

在开发板标题选择 V2.0，再载入 V2 Bootloader + App。运行后由固件自动启动 App，RS485 收到心跳即可选择协议命令读取版本、电压。PC0 使用主旋钮，PC1  在右侧 V2 信号卡调节。DAC0 显示固件实际写入结果。升级步骤见 docs/releases/v0.5.0.md。

## 定时器编号

“定时器”面板采用 GD32F470 的 `TIMER0`～`TIMER13` 编号。STM32 HAL 的 `TIM1`～`TIM14` 按相同外设基地址分别对应 `TIMER0`～`TIMER13`。例如 `TIM2` 的地址 `0x40000000` 在面板中显示为 `TIMER1`，`TIM8` 对应 `TIMER7`，`TIM14` 对应 `TIMER13`。

固件通过外设寄存器配置计数、PWM、输入捕获与中断，面板显示实际执行状态。选择具体实例可查看通道输出、比较/捕获值和 PWM 占空比。

## 主题颜色

打开“设置”，在“主题颜色”中选择蓝色、青色、绿色、紫色、玫红或琥珀。导航、按钮、链接与焦点提示会立即应用所选颜色。色块上的勾选标记显示当前选择，也可用方向键选择颜色。

软件将主题保存到当前用户配置，下次启动时自动恢复。Linux 桌面会话使用不同本地端口时也会恢复该选择。
