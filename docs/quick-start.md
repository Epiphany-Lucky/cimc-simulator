# 第一版使用说明

## 打开

- Windows 完整包：完整解压，双击 `CIMC-Studio.exe`。
- HTML 专用包：完整解压，双击 `Open-Web.cmd`，保持服务窗口开启。
- 两种界面均使用本地 ARM 内核。所有文件保存在本机，无真实开发板、COM 口或 CH340 驱动要求。

## 先验证示例

1. 点击“载入示例固件”。这会加载真实 Keil 编译的 HEX 和 16 条清楚可见的新增跳线。
2. 点击“运行”，稍候 OLED 显示 `CIMC LAB / FIRMWARE LIVE`；CH340 终端出现启动消息。
3. 按 KEY1–KEY6，固件读入 GPIO，更新 LED，并在 OLED 显示按键次数。
4. 串口输入 `L` 翻转 LED，输入 `C` 清空计数；`ACK` 由 MCU 固件生成。
5. 点击“我的接线”删除一条 LED 跳线，该 LED 不再由原 GPIO 驱动。点击两个排针端点可重新连线。保存/打开接线使用 JSON 文件。

## RS232 / RS485

V1.0 的两种收发器共用 USART1。示例默认插入 RS485 的 H6 跳线。

切换 RS232：暂停 → 删除 H6.1↔H6.3 和 H6.2↔H6.4 → 新增 H6.3↔H6.5 和 H6.4↔H6.6 → 切到 RS232 页签 → 运行 → 发送 `L`。

切回 RS485 时恢复原两条 H6 跳线。不要同时连接两种收发器的接收输出。终端页签不会自动改变电路。

## 使用自己的固件

导入 Keil 输出 `.hex` 或 `.bin`。BIN 默认装载地址 `0x08000000`，必须与链接地址一致。HEX 校验和、Flash 范围和复位向量会被检查。

空白接线需要手动连接 LED/KEY 和 H6/H7；MCU 固定连接按 V1.0 原图保留。导入新固件和复位会保留当前新增跳线；“载入示例”会明确替换为示例跳线。

本版支持 Cortex-M4 机器码、GPIO、轮询 USART、GPIO 软件 I²C OLED 和基础 SysTick。UART 中断、DMA、硬件 I²C、定时器、ADC、SD 卡、SPI Flash 等尚未实现。相关寄存器访问会报告诊断；本版不能保证运行任意 Keil 工程。建议先用无需 RTOS、外设中断和 DMA 的最小程序验证。

数字键 1–6 可按下对应 KEY，Space 运行/暂停；设置中可关闭快捷键或减少动画。OLED 可导出 PNG，串口和诊断可导出文件。
