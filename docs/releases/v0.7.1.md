# CIMC Studio 0.7.1

修复 V1 运行使用 180 MHz Over-Drive 的固件时的初始化停机。PMU 高驱动及切换就绪状态现在根据固件实际写入的控制位更新，适用于 GD32/STM32 HAL 兼容的寄存器访问流程。

在 PROJECT1 上，旧仿真没有返回 Over-Drive 就绪位。HAL 等待超时后，程序进入 `0x08000E50` 的错误循环，GPIO 初始化尚未执行。新内核使用同一份 HEX 和原六条跳线继续运行，点亮 LED1、LED3、LED5、LED6。

支持 Windows 安装版、便携版、HTML 本地包、Ubuntu/Debian 安装版和 Linux 便携版。高驱动就绪属于功能仿真，实物稳压器的电压与切换时间需要在硬件上验证。
