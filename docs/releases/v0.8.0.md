# CIMC Studio 0.8.0

V1、V2 增加串口接收 DMA。固件配置 DMA0 或 DMA1 后，仿真引擎按实际寄存器将收到的数据写入 SRAM，更新剩余数量并触发已使能的 DMA 中断。支持 GD32F470 八个 USART/UART 实例的接收请求映射，以及直传的普通模式和循环模式。

原版 DEMO4 的 `HAL_UARTEx_ReceiveToIdle_DMA()` 已在两块板上验证。USB CH340 使用 115200、8 数据位、无校验、1 停止位。短帧走 USART IDLE，128 字节满缓冲区由 DMA 完成中断处理。含 `00`、`FF` 的内容按原始字节回显，固件随后重新启动接收。

本版提供 Windows 安装版、便携版、HTML 本地包、Ubuntu/Debian 安装版和 Linux 便携版。支持范围为串口接收直传至 SRAM。发送方向、其他外设的 DMA、内存到内存、DMA FIFO、突发和双缓冲仍需分别建模。串口终端按批送入数据，实板的逐位时序和总线仲裁需要在硬件上核对。
