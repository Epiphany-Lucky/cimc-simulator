# CIMC Studio 0.3.0

新增Windows与Ubuntu/Debian的可安装版本，内置固件执行内核，无需安装Python或Keil。

- **Windows**：`CIMC-Studio-0.3.0-Setup-x64.exe`，当前用户安装、中文向导、开始菜单、可选桌面快捷方式，支持升级和卸载。
- **Ubuntu/Debian amd64**：`cimc-studio_0.3.0_amd64.deb`，安装后从应用菜单打开，在系统默认浏览器显示工作台。目标Ubuntu22.04+/Debian12+，需已安装图形浏览器。
- **Linux便携目录**：`CIMC-Studio-0.3.0-linux-x64.tar.gz`，完整解压后执行 `./cimc-studio`。

Linux安装命令：

```bash
sudo apt install ./cimc-studio_0.3.0_amd64.deb
```

Linux重复启动复用现有工作台；“退出应用”立即结束会话，全部页面关闭后180秒无客户端活动也会自动退出。Windows关闭主窗口时停止自有内核。卸载保留用户导出文件和浏览器数据。

保留V1固定接线、手动LED/KEY、OLED显示、ADC旋钮、SPI Flash、串口模式切换和原图阅读。外设仍是已记录的功能子集，不保证任意Keil工程兼容。

安装说明及验证边界见随包 `docs/install.md`、`docs/validation-v0.3.md`。源码和构建脚本随发行包提供；旧版本发行保持可下载。
