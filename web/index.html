GET STARTED

从第一行代码开始。

一份固件，一块开发板，所有交互都在这里。

  1. 01
    导入 HEX 或 BIN

    选择 Keil 编译文件；Bootloader 与多个应用可在“多固件”中一起烧录。各 BIN 需填写链接地址。

  2. 02
    连接实际排针

    依次点击空闲 GPIO 与 LED/KEY 排针添加跳线。板载外设和系统跳帽已锁定，H6 通过接口选择切换。

  3. 03
    运行，与固件交互

    点击按键、观察 OLED 和 LED，或在串口终端发送消息。Space 可运行 / 暂停。

这是受支持外设范围内的功能仿真。遇到未实现的访问，请查看诊断面板。
