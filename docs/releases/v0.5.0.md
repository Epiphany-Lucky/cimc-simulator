# CIMC Studio 0.5.0

2026-11-16 · 开发预览

## CIMC V2 板卡

开发板标题处新增 V2.0 选项，使用与 V1 一致的原理图接线界面。随软件提供原始五页 V2 原理图，可翻页、缩放和下载。U2/U3、LED、KEY、OLED 及通信跳帽采用原图脚号，固定铜线由原理图确定，用户和代码示例添加的跳线可以增删。

点击“载入 V2 Bootloader + App”可共同烧录本次提供的两份实际固件，同时载入参考跳线并选择 RS485。固件自己执行 SysTick 倒计时、Bootloader 跳转和应用初始化。首次软件 I²C 初始化需执行约6100万条指令，可观察指令计数。

V2 USART1 固定 PD5/PD6，RS485 方向控制 PE8。H10/H11/H12 跳帽可拆接，删除和重接跳线会影响实际串口通信。OLED 固定 PB8/PB9，板载 VR1 固定接 PC0，PC2 经 H7 跳帽可连接参考电压。PC1 的外接模拟输入使用参考跳线，DAC 由固件寄存器配置并通过实际引脚使用。

板载 GD25Q40E 按原图连接 SPI0 PB3/PB4/PB5 和 PA15。新增实际 Keil HEX/BIN 验证读 ID、页编程和扇区擦除。

协议区可生成所选设备 ID 的命令和 CRC。应用升级先发送“进入 Bootloader”，进入后发送“准备接收升级包”，用“发送 BIN 文件”发送含头的 app_update.bin，收到固件应答后发送“写入应用并重启”。串口回复、内部 Flash 擦写、系统复位和再次进入 App 均由 ARM 机器码执行。

工程导出保存板卡、接线、固件与实际内部 Flash 内容。跨板导入先完整校验再恢复，拔掉的跳帽也会随工程保存。PT100 软件部分已移除。

## 软件内更新

设置中可检查并下载更新，查看进度。下载完成后自动检查大小和 SHA-256，保存工程后点击“安装并重启”。Windows 沿用实际安装目录，退出当前应用后安装并重新启动。Ubuntu/Debian 系统安装通过系统授权执行，Linux 便携版可打开已校验包所在目录。下载中断和校验失败可重试。

## 发布与验证

提供 Windows 安装版、Windows 便携版、HTML 本地包、Ubuntu/Debian DEB 和 Linux 便携包。验收记录保存在 docs/validation-v0.5.md，发行附件包含 SHA-256 清单。

后续版本继续同步源码、软件和公告，在新版发布验收成功后清理被取代的安装分发文件，保留源码、标签、公告和验证记录。

## 支持范围

本版提供 GPIO、轮询串口及 USART RX/IDLE 中断、GPIO I²C OLED、SysTick、内部 FMC、ADC、DAC 和板载 SPI Flash 的功能模型。V2 每条执行指令推进240个 SysTick 输入 tick，倒计时通过实际中断代码推进。DMA、嵌套中断、以太网完整控制器、RTOS、逐周期与实板电气行为仍需独立实现和验证。
