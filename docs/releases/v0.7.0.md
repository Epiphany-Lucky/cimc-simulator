# CIMC Studio 0.7.0

打开“串口终端”，选中通道后点击“串口参数”，即可选择自动跟随固件，或手动指定波特率、数据位、校验位和停止位。波特率可从常用值选择，也可输入自定义值。每个通道可独立设置，手动参数随工程保存。

固件初始化串口后，终端显示其实际帧参数。手动参数与固件不匹配时，仿真会提示并拦截收发。终端继续支持 ASCII、HEX 与现有 RS232/RS485 接线模式。

DEMO3 使用 USB · CH340 和 `115200 8N1`。载入 `MDK-ARM/build/CIMC_DEMO/CIMC_DEMO.hex`，将 KEY1 接到 PA4，运行后按 KEY1 可收到 `HELLO`。新增接收代码的 21:11 构建通过 `HAL_UART_Receive_IT()` 接收终端输入，并由固件回复 `uart data: …`。V1 现使用与 V2 共用的 RXNE/IDLE 中断路径，修复启动时的中止。

支持 V1.0 和 V2.0 的串口功能仿真。接线仍使用板卡原理图映射。发送中断、DMA、物理 COM、硬件流控、9 位数据和电气时序不在本版范围内。

本版提供 Windows 安装包、便携版、HTML 本地包、Ubuntu/Debian 安装包及 Linux 便携包。安装方式和实际交付记录见仓库的 `docs/install.md` 与 `docs/validation-v0.7.0.md`。
