# CIMC Studio 0.5.1

2026-11-16 · 开发预览

## DEMO1 启动兼容修复

修复 HAL 时钟初始化使用外设位带地址时中止的问题。此前用户提供的 `CIMC_DEMO.hex` 执行到第764条指令、PC `0x08000BCA` 时，访问 `0x42470060` 被判为未映射内存。该地址对应 RCC_CR 的 PLLON 位。新版将字对齐的外设位带访问转交现有寄存器模型，读取返回目标位，写入仅取值的最低位并保留其他位。

用户工程的原始源代码和 HEX 可继续使用。该 DEMO 由 SysTick 推进调度器，在 PD8～PD13 输出六路静态 LED 状态 `1、0、1、0、1、1`。

## 接线与观察

选择 V1.0 并载入自己的 `CIMC_DEMO.hex`，LED1～LED6 对应 PD8、PD9、PD10、PD11、PD12、PD13，再点击运行。本次用户工程已有这六条正确跳线，升级后可继续使用保存的接线工程。

该 DEMO 的主循环只运行 LED 调度任务，OLED 保持关闭、串口没有输出符合这份固件的内容。LED 为静态显示，预期 LED1、LED3、LED5、LED6 点亮。

## 发布与验证

提供 Windows 安装版、Windows 便携版、HTML 本地包、Ubuntu/Debian DEB 和 Linux 便携包。设置中的“检查更新”可发现新版，下载后进行大小与 SHA-256 校验，再安装重启。实际验收和发布结果见 `docs/validation-v0.5.1.md`，发行附件附带 SHA-256 清单。

独立位带机器码与回归检查覆盖 PLL 控制、GPIO 输出、最低位写入、其他位保留及未知底层寄存器诊断。本次支持范围为字对齐外设位带访问，SRAM 位带及完整 STM32F427 外设兼容性仍需独立实现和验收。V1/V2 原有功能模型边界继续适用。
